# 代码职责整理

本次检查覆盖后端模块依赖、服务与支撑组件的职责，以及四个前端项目各自的源码。排除依赖目录、构建产物、第三方资源和备份。

## 调整内容

| 位置 | 原问题 | 调整 |
| --- | --- | --- |
| 后端公开缓存 | 切面直接识别文章、评论、配置 Service 实现和方法名，业务与缓存规则相互耦合 | 通过 `common/annotation/PublicCacheRead` 声明外层查询范围；切面按声明处理，写保护复用已有 `CacheEvict.condition` |
| Blog 分类和标签文章页 | 两个页面除路径、字段和文案外实现相同 | 合并为 `Front-Blog/src/view/Taxonomy/index.vue`；两个路由分别传入类型，保留原 URL、搜索、分页和响应式样式 |
| Blog 展示转换 | 组件展示字段转换放在 `api` 目录 | 移至本项目 `src/shared/presentation.js`，同步全部调用 |
| Blog 密码校验 | 表单校验放在请求模块 | 移至本项目 `src/shared/form.js` |
| Admin 表单处理 | 空白值转换和密码校验混在格式化模块 | 移至本项目 `src/form.js`；`format.js` 保留时间、计数和比例展示 |

Home、CV、Blog、Admin 按独立前端项目处理，没有新增项目间共享模块、导入或依赖。Home/CV 本次没有保留源码改动；仓库原有 `Front/shared` 代码未修改。

后端仍保持 `server → common/entity` 的依赖方向。各业务自己的事务、行锁顺序、锁后权限复核、SQL 范围和失败补偿继续留在对应业务中；没有为相似的 CRUD 流程增加公共父服务。没有新增第三方依赖，没有修改 HTTP 接口和数据库结构。
